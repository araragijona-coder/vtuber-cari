# Scavenged Audio

Módulos de audio sintético aislados.

Reglas:
- preferir Web Audio API estándar;
- inicializar AudioContext después de interacción del usuario cuando el navegador lo requiera;
- ningún fallo de audio debe romper la UI;
- no mutar estado global de la aplicación;
- exportar una API pequeña y explícita.

Estética objetivo de esta colección: cyberpunk violeta / rojo fuego.
