# Scavenged Art — Cyberpunk Bōsōzoku

Curated asset staging area for the cyberpunk/bōsōzoku visual direction.

## Required visual filter
- Dark violet / neon violet: #8b00ff
- Fire red: #ff1a1a
- Japanese 1980s/1990s street-bike influence
- Neon, asphalt, night-city, HUD/glitch language

## Legal acquisition rule
Only assets with a source license explicitly verified are eligible for import. CC0/public-domain assets are preferred. Search results, previews, and forum reposts are not treated as proof of redistribution rights.

## Buckets
- waifus/: character/pilot references and assets
- bikes/: motorcycle/vehicle references and assets
- backgrounds/: streets, asphalt, night city, HUD/UI and glitch material
- trash/: intentionally retained low-quality/glitched material only when redistribution rights are also verified

Every imported file must have a matching ASSET_MANIFEST.json entry with source URL, license, author when available, acquisition date, and verification status.
