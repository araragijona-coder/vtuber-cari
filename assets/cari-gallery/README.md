# Cari Gallery

This directory is the generated image gallery for Cari reference assets.

Images are generated by scripts/generate_cari_assets.py through the current Pollinations image API. The GitHub Actions workflow .github/workflows/generate-assets.yml can be launched manually from the Actions tab.

## Required repository secret

Create a repository secret named:

POLLINATIONS_KEY

The key is injected only into the workflow environment and is never written into the repository.

The current Pollinations documentation describes generation through https://gen.pollinations.ai/image/{prompt} and requires an authenticated API key for generation.

Do not put API keys in prompts, generated filenames, committed code, or workflow YAML.

## Output policy

- PNG only.
- Existing files are preserved by default.
- Enable the workflow's overwrite input to regenerate existing assets.
- The workflow commits generated PNGs back to the development branch.
