# Cari Gallery

This directory stores generated Cari gallery images.

## Source

Images are generated by:

`scripts/generate_cari_assets.py`

using the public GET endpoint:

`https://image.pollinations.ai/prompt/{prompt}?width=1024&height=1024&nologo=true`

No Hugging Face integration or repository-configured generation secret is used by the current workflow.

## Automation

`.github/workflows/generate-cari-assets.yml`:

- runs on manual `workflow_dispatch`;
- runs weekly by schedule;
- writes PNGs to this directory;
- commits only changes under this directory;
- pushes to `fix/native-windows-foundation` with the built-in GitHub Actions `GITHUB_TOKEN`.

The generated images remain reference assets until visually approved; generation does not make an image part of Cari's canon automatically.
