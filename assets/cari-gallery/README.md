# Cari Gallery

This directory is the generated image gallery for Cari reference assets.

Images are generated by scripts/generate_cari_assets.py through the public
Pollinations image endpoint and the GitHub Actions workflow
.github/workflows/generate-assets.yml.

## Run from GitHub Actions

1. Open the repository's Actions tab.
2. Select Generate Cari Assets.
3. Select Run workflow.
4. Choose model hint, dimensions, seed and overwrite.
5. Open the resulting cari-gallery-* artifact to retrieve the generated PNGs.

## Authentication

This workflow intentionally requires no user-configured GitHub Secret, PAT,
Pollinations account or POLLINATIONS_KEY.

The generator uses the public image route:

https://image.pollinations.ai/prompt/{prompt}

Provider availability, rate limits and endpoint behavior can change. A provider
failure is reported as a failed generation rather than silently creating fake
assets.

## Output policy

- PNG only.
- Existing files are preserved by default.
- Enable the workflow's overwrite input to regenerate existing assets.
- Generated files are uploaded as an Actions artifact rather than pushed back
  into the repository, so this workflow does not need write credentials.
- Generated images are references/proposals until visually reviewed and approved;
  they do not become Cari canon automatically.
