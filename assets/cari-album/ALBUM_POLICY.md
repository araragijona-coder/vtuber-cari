# Política del álbum visual de Cari

## Estados

- **READY_TO_CATALOG:** el PNG está dentro del álbum y será mostrado por el catálogo automático.
- **LICENSE_REVIEW:** la imagen necesita revisión de procedencia/licencia antes de promoción.
- **PRODUCTION_READY:** la imagen fue aprobada expresamente para uso del producto.

El catálogo automático solo registra la existencia y ubicación del archivo. **No considera una imagen aprobada para producción**.

## Procedencia

Para cada obra artística real debe poder determinarse, cuando corresponda:

- autor;
- fecha;
- fuente/procedencia;
- licencia o permiso;
- restricciones comerciales;
- terceros incluidos;
- versión del paquete.

## Separación

El álbum visual no modifica por sí mismo el comportamiento del avatar, el renderer ni el motor de streaming.
