# Cari — base visual de expresiones PNG

Estado: BASE_ART_V0 / no final.

Estos PNG son assets visuales base para el Action Store de Cari Studio. Son transparentes y comparten el mismo encuadre y diseño.

Expresiones incluidas:
- neutral
- happy
- angry

Especificación visual aplicada:
- chica de piel morena;
- cabello mediano marrón;
- inner hair marrón claro;
- ojos marrones con pupilas blancas y redondas;
- cola de caballo;
- ahoge centrado;
- curita en la nariz;
- ropa deportiva de corredora: remera ajustada/atada a la cintura y shorts/bike-shorts negros;
- estilización intermedia entre chibi 2D y personaje 3D estilizado;
- sin diademas, hairpins, accesorios, objetos adicionales ni prendas extra.

Los archivos son un punto de partida funcional para probar el sistema PNGTuber. No representan todavía el arte final, un rig Live2D ni un modelo VRM.
