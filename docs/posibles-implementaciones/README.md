## REFERENCIAS EXTERNAS
Usar otros juegos para entender principios y patrones. No copiar literalmente personajes, cartas, economía, mapas, UI, assets, código, progresión o estructuras comerciales.

Flujo recomendado: referencia → observación → principio → adaptación → diferencia propia → validación.

## MOVIMIENTO Y 2.5D
Se pueden estudiar anticipación, aceleración, frenada, recoil, camera follow, shake, parallax, motion trails, hit stop, impact frames, zoom, profundidad simulada y composición personaje + motocicleta.
Cada técnica debe responder qué información o sensación comunica al jugador.

## RELACIÓN CON CEREBRO Y OBRERO
El Cerebro puede crear, comparar y validar propuestas.
El Obrero solo implementa una propuesta cuando una tarea explícita la autoriza.
