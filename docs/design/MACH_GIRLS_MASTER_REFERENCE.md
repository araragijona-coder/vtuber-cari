## 5. World calendar and foundational lore

### CURRENT PROPOSED WORLD CALENDAR

The historical lore establishes the Enfermedad del STOP as an old viral threat that disrupted cellular activity and made maintaining sufficient activity and velocity fundamental to survival. | Engine role | Core function |
|---|---|
| **STRIKER / DPS** | Offensive pressure, burst, speed, BREAK exploitation and damage-focused openings. |
| **DEFENDER / TANK** | Survival, protection, shield or mitigation and defensive response. |
| **SUPPORT / HEALER** | Healing, support, Energy or tempo assistance, cleansing and protection. |
| **DEBUFFER / CONTROL** | WEAK/EXPOSED, setup, threat reduction and control-oriented interactions. |

These technical roles are combat functions, not personality categories.

## Phase 25 — Current 2.5D Combat Presentation

### CURRENT / VERIFIED IMPLEMENTATION DIRECTION

The current combat scene is a complete 2.5D presentation layer around the existing semi-real-time combat foundation.

The presentation target is explicitly not `two sprites + cards`.

It includes:

```text
2.5D battlefield
character presence
motorcycle presence
enemy presence
depth
combat timer
damage feedback
ability/card feedback
Energy
BREAK
BURST
telegraphs
camera motion
impact effects
motion trails
particles
lighting
parallax
layered UI
```

### Layer architecture

```text
BACKGROUND
→ FAR_PARALLAX
→ MIDGROUND
→ ENEMY
→ COMBAT_FX
→ CHARACTER_MOTORCYCLE
→ FOREGROUND_FX
→ HUD
→ CARDS
```

Depth is simulated through scale, offsets, z-order, parallax, lighting/intensity hints and interpolated camera motion. No 3D engine is introduced.

### Character + motorcycle

The combat renderer treats the rider and motorcycle as one logical visual composition. Relative scale/offset and a shared anchor are part of the presentation contract.

Current character and motorcycle placeholders are technical fixtures only:

