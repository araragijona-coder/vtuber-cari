# Mach-Girls — Creative Direction

## Status

```text
Rocket Bunny Petty
= HISTORICAL / ORIGINAL WORKING TITLE

Mach-Girls
= PROPOSED CURRENT FRANCHISE / DESIGN DIRECTION
```

This document records a creative pivot. It does **not** authorize a commercial/legal rename.

The repository name, branch names, URLs, runtime paths, historical file names and existing assets remain unchanged by this document.

The historical Rocket Bunny Petty material remains necessary evidence for understanding how the project evolved.

## 1. Franchise concept

PROPOSED CURRENT FRANCHISE / DESIGN DIRECTION:

> **La chica obsesionada con romper la barrera del sonido.**

The project should no longer be conceptualized only as the story of one protagonist. The long-term direction is an expandable universe of:

```text
girls
+
motorcycles
+
speed
+
gangs
+
rivalries
+
technology
+
personalities
+
semi-real-time combat
+
cards / skills
+
2.5D anime
+
cyberpunk
+
bōsōzoku
+
humor
+
drama
```

Yuri remains a central protagonist/personality. A future roster should expand the universe rather than replace Yuri or turn every character into a Yuri clone.

## 2. Historical continuity

The existing lore in LORE_Y_DISENO.md remains the current historical/reference layer for Rocket Bunny Petty's established world material.

This creative pivot does not retroactively rewrite:

- historical lore;
- Phase 14–16 evidence;
- prior combat research;
- prior card identities;
- saved historical labels;
- existing runtime mechanics.

The distinction is intentional:

```text
HISTORICAL
= what the project previously established

CURRENT
= what is implemented now

PROPOSED
= what Mach-Girls intends to become

OPEN DESIGN QUESTION
= unresolved design requiring a later decision
```

The naming pivot is therefore a **creative direction change**, not a historical rewrite.

## 3. Yuri and the wider cast

Yuri remains a protagonist/central character.

Her existing characterization and lore should not be erased merely because the franchise broadens.

Future characters should be authored from their own:

```text
personality
+
role
+
driving style
+
combat identity
+
visual language
+
relationship function
```

The franchise should support distinct archetypes, factions and rivalries rather than reskinning the same mechanical identity.

## 4. Narrative name contrast

PROPOSED NARRATIVE THEME:

The original Rocket Bunny Petty name may deliberately feel smaller or less legendary than the achievement Yuri eventually pursues.

Conceptually:

> Una chica cuyo nombre no parece anunciar una heroína legendaria puede terminar convirtiéndose en alguien capaz de desafiar la barrera del sonido.

This is a narrative-theme hypothesis, not canon dialogue or finalized story text.

## 7. Role identity

PROPOSED DESIGN PRINCIPLE:

> CLASE ≠ SOLAMENTE DAÑO

A future character's role should be readable in the mechanics, presentation and behavior.

### STRIKER / DPS

```text
rapid attacks
multi-hit
burst damage
execution
BREAK exploitation
speed
momentum
```

### DEFENDER / TANK

```text
shield
damage reduction
interception
protection
counter
stability
```

### SUPPORT / HEALER

```text
healing
regeneration
buff
cleanse
Energy support
cooldown support
protection
emergency rescue
```

A support/healer may still deal incidental damage or have an attack basic. The design rule is that its primary mechanical identity should not repeatedly contradict its class and personality.

### DEBUFFER / CONTROL

```text
WEAK
EXPOSED
defense reduction
slow
telegraph manipulation
BREAK preparation
target control
```

Role identity should also appear in:

```text
cards
effects
animation
VFX
sound hooks
UI
behavior
```
