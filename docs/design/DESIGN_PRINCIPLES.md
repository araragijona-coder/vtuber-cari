# Rocket Bunny Petty — Design Principles

1. Identity over scale — keep the game compact and coherent. PROPOSED.
2. Mechanics must create decisions — integration requires meaningful decision differences; human preference remains UNKNOWN.
3. Prototype before integration — HIPÓTESIS → PROTOTIPO → SIMULACIÓN/TEST → ANÁLISIS → DECISIÓN → INTEGRACIÓN O RECHAZO.
4. Evidence before claims — use VERIFIED, INSPECTED, INFERRED, PROPOSED, UNKNOWN and NOT RUN.
5. No win-rate-only decisions — inspect decisions, resources, timing, risk and outcomes separately.
6. Player decisions over feature count — prefer fewer systems with clearer choices.
7. Personality through systems — mechanics, enemies and character reactions should express Rocket Bunny identity. PROPOSED.

Research discipline: isolate variables; use paired seeds; freeze states for forced-choice work; avoid invented utility functions; separate manual counterfactuals from sampled states; record limitations; prototype support is not runtime approval.
